# TSCC

An experimental compiler for TypeScript projects built using [TSGO](https://github.com/theoparis/typescript-go) and [LLVM](https://github.com/llvm/llvm-project).

## Running the Demos

> Note: currently, a fork of tsgo is required to be able to utilize the parser.

```
git clone https://github.com/theoparis/tscc
cd tscc
git clone https://github.com/theoparis/typescript-go
go run . ./examples/vga.ts
```
